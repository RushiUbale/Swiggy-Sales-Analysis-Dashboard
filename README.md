## Project Overview

This project is an interactive Excel dashboard developed to analyze Swiggy sales performance.

## Dashboard Features

- KPI Cards
- Interactive Charts
- Pivot Tables
- Pivot Charts
- Slicers
- Sales Analysis
- Category-wise Analysis
- City-wise Analysis

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
